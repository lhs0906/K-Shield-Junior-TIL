## 2. 학습 내용 및 실습

### 2-1. rsyslog 데몬

1. rsyslog 데몬 : 리눅스 초기에 사용했던 syslog의 성능을 대폭 강화한 패키지로, 멀티 스레드 지원, TCP 지원, SSL 및 TLS 지원, 데이터 베이스 지원, 보내는 목록 제한, 메세지 일부 필터링, 출력 포맷 제어 등 다양한 기능을 지원.

* rsyslog 설정파일

```bash
$ /etc/rsyslog.conf

# facility.proirity action <- 기본 구성 형식

# facility : 일종의 서비스를 의미. 메세지를 발생시키는 프로그램의 유형
# priority : 위험의 정도를 의미. 설정한 수준보다 높으면 메세지 기록
# action : 메세지를 보낼 목적지나 행동들에 관한 설정으로 보통 파일명을 기입
```

<br>

2. logrotate : 로그 파일의 크기가 커지는 것을 방지하기 위해, 로그 파일을 여러 개로 분할해주는 프로그램. 지동 로테이션 기능, 압축기능, 제거 등을 지원한다.

* 각각의 로그 파일은 하루, 일주일, 한달 단위로 로테이션된다.
* 명령행을 통해서 logrotate 사용이 가능하지만, 현재는 /etc/cron.daliy 파일에 등록되어 스케줄링된다.

<br>

* logrotate 설정 파일

```bash
$ /etc/logrotate.conf

# logrotate [option] Configuration File <- logrotate 사용법

# 사용예시 : logrotate -f /etc/logrotate.conf
# f 옵션 : 강제로 환경 설정 파일을 읽어 들여서 실행
```

### 2-2. 리눅스 주요 로그 파일

1. /var/log/messages : 시스템에서 발생하는 표준 메세지가 출력되도록 기록되는 파일로, 대부분의 로그가 이 파일에 기록된다.
* 날짜 및 시간, 메시지가 발생한 호스트명, 메시지를 발생한 내부 시스템이나 응용 프로그램의 이름 후 ':'으로 구분하고 발생된 메세지순으로 기록되어 나타낸다.
* 일반 텍스트 형식으로 기록되어 있으며, cat 또는 vi 같은 명령어로 root 사용자만 읽기가 가능하다.

![alt text](<image/스크린샷 2026-10-22 오후 6.06.36.png>)

<br>

2. /var/log/wtmp : 사용자의 성공한 로그인/로그아웃 정보, 시스템의  Boot/Shutdown 정보에 대한 히스토리를 담고 있는 로그 파일이다.
* 바이너리 파일로 되어 있어, cat 또는 vi 명령어로는 읽을 수 없다.

* 관련 명령어 -> last : 시스템이 켜진 이후(혹은 로그 파일이 유지되는 동안) 발생한 모든 로그인/로그아웃 기록을 /var/log/wtmp 파일(바이너리 로그 파일)에서 읽어와 화면에 출력.
시스템에 로그인(접속)하고 로그아웃한 사용자의 이력(로그)을 확인할 때 사용하는 유용한 명령어. 시스템 보안 감사나 사용자 접속 기록을 추적할 때 주로 활용됨.

<br>

3. /var/log/btmp : 실패한 로그인 시도에 대한 기록을 담고 있는 로그파일. 이것도 바이너리 파일로 되어 있어 cat과 vi로 읽을 수 없다.
* 관련 명령어 -> lastb : 시스템에 로그인 실패(부정한 접근 시도) 이력을 확인할 때 사용하는 명령어.
정상적인 로그인을 기록하는 last 명령어와 달리, 비밀번호를 틀렸거나 권한이 없는 계정으로 로그인을 시도하다가 실패한 기록만 모아서 보여준다.
시스템 로그인 실패 기록이 저장되는 /var/log/btmp 파일(바이너리 로그 파일)을 읽어와 출력합니다.
⚠️ 권한 주의: /var/log/btmp 파일은 보안상 중요한 정보(해커의 IP나 무차별 대입 공격 시도 등)를 담고 있기 때문에, 주로 root 권한(또는 sudo)으로 실행해야 전체 기록을 정확히 볼 수 있다.

<br>

4. /var/log/lastlog : 가장 최근에 성공한 로그인 기록을 담고 있는 로그 파일.
이것도 바이너리 파일로 되어 있어 cat과 vi로 읽을 수 없다.
* 관련 명령어 -> lastlog : 시스템에 등록된 모든 사용자의 가장 최근 로그인 시간(최종 접속 기록)을 한눈에 확인할 때 사용하는 명령어.
사용자가 언제 마지막으로 시스템에 접속했는지 파악할 수 있어, 오랫동안 사용하지 않는 휴면 계정을 찾아내거나 보안 감사를 할 때 매우 유용함.
etc/passwd 파일에 등록된 모든 사용자 계정을 기준으로, 각 사용자의 가장 마지막 로그인 정보를 /var/log/lastlog 파일에서 읽어와 출력한다.

<br>

### 2-3. 리눅스 기타 로그 파일

1. /var/log/secure : 인증에 기반한 접속과 관련된 로그가 기록되는 로그 파일

2. /var/log/cron : cron 관련 정보가 기록되는 로그 파일

3. /var/log/xferlog : FTP 접속과 관런된 작업이 기록되는 로그 파일

4. /var/log/boot.log : 부팅 시 파일 시스템 체크, 서비스 데몬 관련 정보가 기록되는 로그파일

5. /var/log/dmesg : 부팅 시에 출력되는 모든 메시지가 기록되는 로그파일. dmesg 명령어로 출력이 가능.
