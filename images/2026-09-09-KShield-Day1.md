## 2. 핵심 이론 정리

### 2.1 UNIX & Linux 개요
**< UNIX 개요 >**
* **대부분 C언어를 기반하여 개발된 운영체제로, 이식성이 강하며 시분할 구성으로 다중 사용자, 멀티 태스킹, 이식성으로 설계되었다.**
* **크게 상업 지향적인 System V계와 연구 개발 지향적인 BSD계로 나뉘어지며, 현재는 두 장점을 모두 취하고 있는 형태이다.**
* **리눅스가 개발되었던 뿌리가 된다.**
* **대표적인 유닉스의 종류로는 System V R4.0, SCO UNIX, SunOS, Solaris 등이 있다.**  
<br>

**< Linux 개요 >**
* **상용 유닉스에 반하여 자유 소프트웨어 재단이 설립되었고, 오픈 라이선스를 주장하며 리누스 토발즈가 개발한 운영체제이다.**
* **타 운영체제와 달리 리눅스 커널과 다른 구성 요소가 무료인 오픈소스 소프트웨어이다.**
* **PC 또는 기타 장비에서의 이식성이 높다.**
* **리눅스의 종류는 크게 데비안 계열 ( 우분투, 칼리 리눅스, 리눅스 민트 ) 과 레드헷 계열 ( 페도라, RHEL, CentOS ) 로 나뉘어진다.**
* **오늘 실습에서 사용한 Rocky Linux는 레드헷 계열에 해당한다.**

<br>
<br>

### 2.2 리눅스 구조와 Shell의 이해
**< Shell 개요 >**
* **쉘은 응용 프로그램과 운영체제 사이에 위치하며, 사용자와 시스템 간의 다리역할을 한다. 즉, 사용자로부터 명령을 받아 해석하고 실행하는 역할을 한다.**
* **운영체제 상에서 다향한 운영체제 기능과 서비스를 구현하는 인터페이스를 제공하는 프로그램이다.**
* **CLI와 GUI로 분류된다.**
* **CLI : 명령 줄(Command Line) 인터페이스를 제공. (ex) 키보드만을 이용하는 것**
* **GUI : 그래픽 사용자(Graphic User) 인터페이스를 제공. (ex) 마우스 사용**

<br>

**< Shell의 기능 >**
* **명령어 해석기 기능 : 사용자와 커널 사이에서 명령을 해석해 전달한다.**
* **프로그래밍 기능 : 여러 명령을 사용해 반복하여 수행하는 작업을 하나의 프로그램으로 제작한다. (Shell Script)**
* **사용자 환경 설정의 기능 : 초기화 파일 기능을 이용해 초기 환경을 설정한다.**

<br>

**< Shell의 종류 >**
* **그래픽 쉘(GUI) : MS 윈도우 환경, 매킨토시 파인더, X 윈도우 시스템 기반 환경**
* **명령줄 쉘(CLI) : 유닉스 쉘(sh, csh, ksh, scsh, zsh), COMMAND.COM, CMD.EXE**

### 3.2 echo 명령어 및 이스케이프 문자

<br>

1. echo : 주어진 문자열을 공백과 개행 문자 등을 포함하여 표준 출력으로 출력하는 명령어.
* 사용법 : echo [옵션] [문자열] 
* 옵션 : -n, -e
* -n : 마지막에 따라오는 개행 문자(newline) 문자를 출력하지 않음.
* -e : 문자열에서 역슬래시(\)와 조합되는 이스케이프 문자를 인용부호( " " ) 로 묶어서 인식.

<br>

2. 이스케이프 문자 종류 ( 실습용 몇 가지만 )
* \a : 경고음 소리 출력
* \t : 수평 탭
* \v : 수직 탭
* \\\ : 역슬래시

<br>

```bash

#echo 옵션 사용
$ echo -e "Hello World\n"
$ echo -n "Hello World"

#이스케이프 문자 사용
$ echo -e "\a"
$ echo -e "\ta"
$ echo -e "\va"
$ echo -e "\\"

```

### 3.3 리다이렉션 (Redirection) & 파이프 (Pipe)
<br>

1. 리다이렉션 : 명령어의 표준 출력 값을 특정 파일에 저장하는 행위. ( > 와 >> )
* \> : 명령어의 표준 출력 값을 파일의 첫번째부터 새로 입력. ( overwrite, 덮어쓰기 )
* \>> : 명령어의 표준 출력 값을 파일의 마지막에 이어서 입력. ( append, 이어쓰기 )

<br>

2. 파이프 : 명령과 명령을 연결할 때 사용. 즉, 명령의 결과를 다음 명령으로 전달하여 처리하도록 할 때 사용된다. ( ' | ' 기호 )
* ' | '  사용법 : $ 명령어 | 명령어

<br>
<br>

```bash

# 리다이렉션 사용

# 스트립트 작성
$ vi text.sh
#!/bin/sh
echo "hello world!!" > file.txt
echo "hi" >> file.txt

# 스트립트 실행
$chmod +x test.sh
$ ./test.sh
$ cat file.txt

```

```bash

# 파이프 사용

# passwd 파일 내용을 출력하되, kisec 문자열과 일치하는 행만을 출력
$ cat /etc/passwd | grep kisec

# 파일 목록을 출력하되, file 문자열과 일치하는 목록만 출력
$ touch file.txt
$ ls -al | grep file

```
