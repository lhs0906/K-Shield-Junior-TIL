## 2. 학습 내용 및 실습

### 2-1. 리눅스 패키지

1. 리눅스 패키지 : 리눅스에 사용되는 프로그램은 소스파일을 압축하여 배포되는데, 일반 사용자들의 쉬운 설치를 위해 패키지 관리 기법이 나오게 되었다. 소스 컴파일을 위한 Makefile, 컴파일 도구, 관련 문서 등이 포함되어 있다.

* 주요 패키지 관리 기법은 rpm, dpkg, YaST 등이 있다.
* 레드헷 계열 : rpm (Redhat Package Manger)
* 데비안 계열 : dpkg (Debian Package Management)
* 수세 계열 : YaST

<br>

2. rpm : 레드헷 사의 패키지 기법이다. 프로그램을 .rpm 형태의 파일로 배포하고, rpm 명령을 사용해 손쉽게 설치/갱신/제거/검증/질의 등의 관리가 가능하다.

* rpm 파일 구성

```bash
$ 패키지 이름-버전-릴리즈.아키텍쳐.rpm
# ex) httpd-2.2.15-69.el6.centos.x86_64
```

* 릴리즈 : 한 버전의 패키지를 몇 번 빌드했는지를 의미한다.
* 아키텍처 : 패키지가 사용 가능한 시스템을 의미한다.

<br>

3. yum(Yellowdog Updater, Modified) : rpm 패키지 설치 시에 가장 많이 발생하는 의존성 문제를 자동으로 해결해준다. 소프트웨어 저장소(repository)에 관련된 패키지들을 모아두고 네트워크를 통해서 의존성을 검사하여 설치 및 업데이트 등을 수행한다.

* yum 사용법

```bash
$ yum [option][command][패키지 파일명]
```

* yum 주요 옵션
* -y : 모든 질의에 'yes'라고 답함
* -v : 자세한 정보를 출력

4. dpkg

* .deb 파일 구성 (rpm과 동일하다)

```bash
$ 패키지 이름-버전-릴리즈.아키텍쳐.deb
# ex) appache2_2.4.29.1ubuntu4.11_amd64.deb
```

<br>

5. apt-get : /etc/apt/sources.list 파일에 패키지 관련 정보를 관리하여 의존성과 충돌성 문제를 해결한다. 

* apt-get은 yum과 마찬가지로 패키지 관리를 위한 명령행 기반의 유틸리티이다.


```bash
$ apt-get [option][command][패키지명]
```

* apt-get 주요 옵션
* -y : 모든 질의에 'yes'라고 답한다.
* -purge : remove 명령 수행 시, 환경 설정까지 같이 제거할 떄 사용한다.

<br>

* apt-get 주요 명령
* update : 패키지 목록을 갱신할 때 사용
* install 패키지명 : 패키지 설치
* remove 패키지명 : 패키지 삭제
* clean : /var/cache/apt/archive에 생성된 파일을 삭제
