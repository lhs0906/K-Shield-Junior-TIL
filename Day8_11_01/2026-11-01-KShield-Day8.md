## 2. 학습 내용 및 실습

### 2-1. 퍼미션과 소유권
1. 퍼미션 : 리눅스 시스템의 모든 소유자와 소유권을 가진 파일과 디렉터리에 접근을 제어해 엑세스 할 수 있도록 해준다.

<br>

2. 소유권 : 파일과 디렉터리를 생성한 사용자가 갖는 권한이다. 보통 계정이름으로 표기되거나 어떤 경우에는 UID로 표기된다.

<br>

### 2-2. 소유권 관리

```bash
$ chown 소유자.그룹 파일/디렉터리 명
```
* .이나 : 으로 표기한다.

### 2-3. 퍼미션의 이해

1. 퍼미션 형식 구조

```bash
rwx(사용자) rwx(그룹) rwx(기타)
```
* r : read 읽기 (4)
* w : write 쓰기 (2)
* x : eXecution 실행 허용 (1)

```bash
ex) 644 -> rw- r-- r--
```

![alt text](<image/스크린샷 2026-10-20 오후 1.51.31.png>)

<br>

2. 퍼미션 예제 : ls의 실행 퍼미션은 기본이 755이다. 만약 ls의 실행권한을 750으로 변경한 후 일반계정으로 ls를 실행할 시, 퍼미션 750은 일반계정의 권한을 주지 않은 것이으므로 Permission denied가 발생한다.

![alt text](<image/스크린샷 2026-10-20 오후 1.54.03.png>)

<br>

3. 4자리 절대모드 퍼미션 (x권한도 있으면 t,s,s로 소문자로 표기, x권한은 없는 단독권한이면 T,S,S로 대문자로 표기된다.)

* SetUID : 파일을 소유한 사용자 -> Owner 권한에 s로 표기됨 (절대 표기값 : 4000)

<br>

* SetGID : 그룹 -> Group권한에 s로 표기됨 (절대 표기값 : 2000)

<br>

* Stiky bit : 기타 -> Other 권한에 t로 표기됨 (절대 표기값 : 1000)

<br>

4. SetUID와 SetGID : 파일을 실행할 때 그 파일의 소유자 또는 그룹의 권한으로 실행되도록 하는 것이다. 시스템에서 작업이 이뤄질 수 있도록 루트 권한이 필요한 경우나 어떠한 시스템 자원을 이용하기 위해 필요하다.

<br>

5. Stiky bit :  리눅스에서는 /tmp 디렉터리가 이 비트에 적용된다. 이 비트를 적용한 파일은 어떤 사용자라도 읽고 쓸 수 있지만 삭제를 할 수 있는 사람은 이 파일을 생성한 사용자만이 삭제 가능하다.
