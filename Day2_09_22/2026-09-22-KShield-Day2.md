### 2-2. 파일 및 디렉터리 목록 보기 (ls)
1. ls 명령어 : 현재 디렉터리 파일의 목록을 표시한다.

<br>

2. ls 명령어의 추가 옵션
* -a : 디렉터리 내의 모든 파일 출력 
* -l : 파일 정보를 표시
* -s : 블록 단위로 파일 크기 표시
* -t : 파일 최근 변경 시간에 따라 정렬해서 출력
* -R : 현재 작업 디렉터리와 하위 디렉터리 모두 출력
* \* : 모든 디렉터리와 그 하위 디렉터리 모두 출력

![alt text](image2/4.ls.png)

<br>

### 2-3. 현재 디렉터리 이름 출력 (pwd) 및 현재 디렉터리 변경 (cd)
1. pwd 명령어 : print name of working directory의 약어로, 작업중인 디렉터리의 이름을 출력한다. 현재 위치해 있는 디렉터리 위치를 알고자 할 때 쓰인다.


<br>

2. cd 명령어 : chage directory의 약어로, 상대경로와 절대경로를 이용하여 현 디렉터리 주소를 변경할 수 있다.

<br>

* 절대 경로 이용 예시 : 최상위(루트) 디렉터리부터 변경할 디렉터리까지 모두 입력하여 변경한다. [ cd /home/user/Desktop ]
* 상대 경로 이용 예시 : 현재 디렉터리를 기준으로 입력하여 변경한다. [ cd ./user/Desktop ]
* 절대경로는 /로 시작하고, 상대경로는 .또는 파일 이름으로 시작한다.


<br>

![alt text](image2/5.pwd,cd.png)

### 2-4. 파일 혹은 디렉터리 복사 (cp)
1. cp 명령어 : 파일 혹은 디렉터리를 복사하며, 원하는 경로 없이 복사할 경우 현재 경로에 자동으로 복사한다.

<br>

< cp 사용법 >
* cp [옵션] [원본파일] [원하는 경로 및 파일명(확장자)]
* cp [옵션] [원본 디렉터리] [원하는 경로 및 디렉터리명]

<br>

< cp 추가 옵션 >
* -a : 원본 파일의 속성, 링크 정보들을 유지하면서 복사
* -r : 디렉터리를 복사하되, 하위 디렉터리들까지 모두 복사 ( 디렉터리를 그냥 복사할 경우 에러가 나므로, -r 옵션을 같이 주어야 한다. )

![alt text](<image2/6. cp.png>)

<br>
<br>

### 2-5. 파일 삭제 (rm)
1. rm 명령어 : 필요 없는 파일을 삭제할 때 사용한다.
* 사용법 : rm [옵션] [파일명]

<br>

< rm 옵션 >
* -r : 하위 디렉터리를 포함한 파일들을 모두 삭제
* -f : 삭제할 것인가라는 메시지 없이 그대로 강제 삭제

![alt text](image2/7.rm.png)

<br>

### 2-6. 디렉터리 생성 (mkdir) 및 삭제 (rmdir)
1. mkdir 명령어 : 새로운 디렉터리를 신규 생성 또는 추가로 생성.
< 사용법 > : mkdir [옵션] 생성 디렉터리 이름 (복수 지정 가능)

<br>

2. rmdir 명령어 : mkdir에 의해 생성된 디렉터리를 삭제. (디렉터리가 비어있을 경우에만 삭제가 가능하다.)
< 사용법 > : rmdir [옵션] 디렉터리 (복수 지정 가능)

### 2-7. 파일 이동 및 이름 변경 (mv)
1. mv 명령어 : 파일을 옮기거나 이름을 변경할 때 사용. 파일명을 지정하지 않을 경우 기존 파일명을 그대로 유지한다.

<br>

< 사용법 >
* 파일 이동 : mv [원본 파일] [이동하려는 경로 및 저장할 파일명]
* 이름 변경 : mv [원본 파일] [변경하려는 파일명]

![alt text](image2/9.mv.png)

### 2-8. 파일 찾기 (find)
1. find 명령어 : 조건에 맞는 파일을 찾아주는 명령어. 기본적으로 하위 디렉터리까지 모두 탐색하며, 파일의 이름부터 수정시간에 이르기까지 주어진 파라미터들과 일치하는 파일을 찾아준다.
< 사용법 > : find [경로] [표현식] [지정 조건]

<br>

< 표현식 >
* -name : 지정된 문자열 패턴에 해당하는 파일 검색
* -exec : 검색된 파일에 대해 지정된 명령 실행

<br>

* 사용 예시 : find / -name "test" -> 파일 이름이 test인 파일을 모두 찾는다는 뜻이다. 만약, 파일 이름에 test가 들어간 파일을 모두 찾고 싶을 경우, "\*test\*" 라고 쓰면 된다.

<br>


![alt text](image2/10.find.png)

### 2-9. 프로세스 상태 확인 (ps)
1. ps 명령어 : process status의 약어로, 현재 사용하고 있는 프로세스의 상태를 점검.
< 사용법 > : ps [옵션]

<br>

< ps 옵션 >
* -ef : 표준 구문으로 시스템의 모든 프로세스 표시
* -u : 실행한 유저와 실행 시간을 표시
* -a : 다른 유저의 프로세스 현황 표시
* -x : 터미널 제어 없이 프로세스 현황 표시


<br>

< ps 사용시 알아둘 것 >
* UID : 유저 ID
* PID : 프로세스 ID (1번)
* PPID : 부모 프로세스 ID (0번)
* swaper : 부팅 시 swaper가 init 또는 systemd를 실행시킨다.

<br>


![alt text](image2/11.ps.png)

### 2-11. 프로세스 종료 (kill)
1. kill 명령어 : 시스템에 문제가 생겼을 때, 해당 프로세스를 강제로 종료하는 기능으로 유용하게 사용된다. 지정한 프로세스에 지정한 시그널을 보낸다.
< 사용법 > : kill [옵션(signal)] [PID]

<br>

< 옵션 (signal) >
* -l : 시그널 리스트 확인
* -9 : 프로세스를 강제로 종료
