### 2-1. vim 모드 전환
1. 일반 모드 ( Normal Mode ) : 키 입력을 통한 vim에 명령을 내리는 모드. 커서 이동, 삭제, 복사 등의 작업을 수행.
< 키 > : ESC

<br>


2. 입력 모드 ( Insert Mode ) : 실제로 문서를 편집하기 위한 모드.
< 키 > : i, o, s, a

<br>


3. 명령 모드 ( Command Mode ) : 명령 입력으로 여러가지 작업을 수행하는 모드. vim의 설정 편집, 다른 파일 열기, 저장 등의 작업 수행.
< 키 > : :, /, ?

<br>


4. 비주얼 모드 ( Visual Mode ) : 명령을 수행할 경우 범위를 지정하는 모드.
< 키 > : v

<br>

### 2-2. vim 일반 모드

< 커서 이동 >
* h : 커서를 왼쪽으로 이동
* j : 커서를 아래로 이동
* k : 커서를 위로 이동
* l : 커서를 오른쪽으로 이동
* \- : 커서를 줄의 처음으로 이동
* e, E : 단어의 마지막 글자로 이동
* w, W : 단어의 첫 글자로 이동
* $ : 문장의 맨 뒤로 이동
* 0 : 라인의 맨 앞으로 이동
* ^ : 문장의 맨 앞으로 이동
* Shift + g : 문서의 마지막으로 이동
* gg, 1g : 문서의 맨 앞으로 이동

<br>

< 화면 스크롤 >
* Ctrl + f : 화면을 아래로 이동
* Ctrl + b : 화면을 위로 이동
* Ctrl + d : 화면의 반을 아래로 이동
* Ctrl + u : 화면의 반을 위로 이동
* Ctrl + e : 한 줄 아래로 이동
* Ctrl + y : 한 줄 위로 이동
* Ctrl + h : 화면의 맨 윗줄로 이동
* Ctrl + m : 화면의 중간으로 이동
* Ctrl + l : 화면의 맨 아랫줄로 이동

<br>

< 편집 ( 삭제, 복사, 붙여넣기, 되돌리기 ) >
* yy : 한 줄 복사
* yny : 현재 라인에서부터 n라인 만큼 복사
* p : 복사된 내용 붙여넣기 ( yy나 dd 중 더 최근에 복사 / 삭제된 내용이 붙여넣기 된다. )
* dd (dnd) : 한 줄 삭제
* dw : 한 단어 삭제
* Shift + d : 현재 커서 위치에서 라인 마지막까지 삭제
* Shift + j : 현재 행의 개행 문자 제거
* u : 되돌리기 (Undo)
* ctrl + r : 재실행 (Redo)

<br>
<br>

### 2-3. vim 명령 모드
1. 명령 모드 시작 : 일반모드에서 ' : ' 를 입력한다.

<br>

2. 찾기 기능 - : / [패턴] / 또는, 그냥 / [패턴]

<br>

3. 치환 기능 - :[범위] s / [검색 문자] / [치환 문자] / ( g )
< 범위 지정 특수 기호 >
* % : 전체 문서에서
* . : 현재 문단에서
* $ : 마지막 문단에서

<br>

< g의 역할 > : g는 global로, 전체 범위에 걸쳐서 검색 후 치환한다. g를 사용하지 않을 경우 처음에 검색된 문자만 치환한다.

<br>

3. 파일 저장, 열기, 종료
* :e [file name]
* :q (종료), :q! (강제 종료, :x도 강제 종료), :wq (저장 후 종료)
* :w (현재 파일명으로 저장), :w [file name] (file name으로 저장)
* :< 범위 > w [file name] : 지정한 범위만 다른 파일로 저장

<br>
<br>

### 2-4. vim 비주얼 모드

1. 블록 지정 (블록 범위는 커서 이동 명령을 통해 원하는 만큼 지정 가능.)
* v : 단어 단위로 블록 지정
* Shift + v : 라인 단위 블록 지정 
* Ctrl + v : 블록 단위 블록 지정

<br>

2. 블록 지정 후 편집
* y : 지정된 블록을 복사
* p : 복사된 블록을 현재 라인 (커서) 아래에 붙여넣기
* d : 지정된 블록을 삭제
* dd : 현재 라인을 삭제

<br>

### 2-5. vim 입력 모드

1. 입력 명령
* i : 현재 위치에서 삽입
* o : 새로운 줄을 아래에 생성하고 삽입
* a : 현재 위치에서 한 칸 앞으로 이동해서 삽입
* s : 현재 위치의 문자를 지우고 입력모드로 전환
* I : 현재 줄의 처음 위치에서 삽입
* O : 새로운 줄을 위에 생성하고 삽입
* A : 현재 줄의 마지막 위치에서 삽입
* S : 현재 위치의 라인을 지우고 입력모드로 전환
